# 概述
fx100 设计了「用户优化」：**订单 size 超过阈值时不向用户收取 keeper 执行费**（由协议 treasury 补贴），适用于市价单与限价/触发单。本专题用 E2E 精确验证该机制对 Market / Limit 是否都成立、边界是否精确、资金流是否闭环，并澄清「市价单不收费、TP/SL 收 ETH」现象的真正根因。

<td>**无论 size 多大**都要求 `executionFee >= gasLimit * tx.gasprice`，否则 revert `InsufficientExecutionFee`。预付 WNT 进 OrderVault。创建时无 size 豁免。</td>

</tr>
</table>
阈值参数：`FX100Keys.executionFeeSubsidizeKey(marketIndex)`（per-market，USD 1e30）。适用所有用户订单：MarketIncrease/Decrease、LimitIncrease/Decrease、StopIncrease、StopLossDecrease。Liquidation/ADL 本身 executionFee=0，不受影响。

<callout icon="🔴" color="red_bg">
	**部署硬性要求（HARD REQUIREMENT）**
	每个市场的 shared-market 配置 JSON **必须显式包含 ****`executionFeeSubsidize`**** 字段，不得省略。**
	- 关闭补贴（当前策略）→ 显式写 `MAX_UINT256`
	- 开启补贴 → 写明确 USD(1e30) 阈值，且需先修 BUG-B03
	- **禁止依赖默认值**：`configureMarket.ts:60` 缺省回退是 `"0"`（=全场免费 + 资金卡死），与代码默认 MAX 相反，漏配静默且后果严重
	- 建议：把 `configureMarket.ts` 的 `?? "0"` 改成缺失即 `throw`，从源头杜绝漏配
</callout>

# 3. BUG-B03（与本专题强相关）
补贴把 `executionFee` 设为 0 后，`payExecutionFee(0)` 早返回 → 用户创建时预付的 WNT **既不付 keeper、也不退用户，永久滞留 OrderVault**。详见 `test/bugs/BugB03_ExecutionFeeSubsidy.t.sol`。本 E2E 在真实 create→execute 链路复现并标注，不在本分支修复。

# 5. 「市价单不收费、TP/SL 收 ETH」结论
**合约侧市价单与 TP/SL 完全对称**，都走同一个 `validateExecutionFee`（`minExecutionFee = gasLimit * tx.gasprice`），合约**无**触发单特殊收费逻辑。
根因是**前端不一致**（测试网/fork 上 `tx.gasprice ≈ 0`）：
<table fit-page-width="true" header-row="true">
<tr>
<td>路径</td>
<td>文件</td>
<td>处理</td>
<td>测试网结果</td>
</tr>
<tr>
<td>市价开仓</td>
<td>`increaseOrderPayloads.ts:115`</td>
<td>用 `feeTokenAmount` 原值，**不加地板**</td>
<td>fee=0 → 不扣 ETH</td>
</tr>
<tr>
<td>TP/SL</td>
<td>`decreaseTpslPayloads.ts:170`</td>
<td>`applyExecutionFeeFloor` 强制 `0.00004 ETH`</td>
<td>每笔扣 ETH</td>
</tr>
</table>
该地板注释称「fee=0 会导致合约 revert」是**错误的**（此时 minExecutionFee 也为 0，不 revert）。**测试网**：市价免费、TP/SL 扣 ETH 属前端地板不一致（可归前端问题，无需改合约）。**主网**（gasprice\>0）：两者都收，不对称消失。此「创建期是否扣 ETH」与「执行期大单免费」是两件事，勿混淆。

# 7. 关键精度 / 陷阱
- **token 模式归一化**：`sizeDelta * indexTokenPrice.midPrice()`，WNT mid=`2000e12`；`= 20000e30` 则 `sizeDelta=10e18`。
- **执行费需非零 gasprice**：`vm.txGasPrice(...)` 设非零，否则掩盖资金流（这也是前端加 0.00004 ETH 地板的原因）。
- **warp 后双刷 oracle**；触发单需 warp 到 validFromTime 后执行。
- **静默取消**：`OrderHandler.executeOrder` try/catch，超限静默取消非 revert；用 `_openLong` 的 assertGt 守卫。
- **B03 断言策略**：`test_*` 断言当前滞留（PASS）；`test_fix_B03_*` + `vm.skip(true)` 描述修复后应退款。
