# v0.3.1 期望差异

本文件只写共享用例在 v0.3.1 下需要改变或收窄的期望；未列出的断言沿用共享设计。

| 共享用例 | v0.3.1 期望 |
|---|---|
| SCN-050 改善/恶化失衡对比 | 验证 v0.3.1 的非负点差口径；“改善侧出现负动态点差并获得更优执行价”不是本版本 PASS 条件 |
| SCN-049 浅流动性极端冲击 | 仍要求记录指数溢出或清算不可用等安全问题；已知旧实现行为不得被改写成 PASS 期望 |
| SCN-053～058 Flash/Relay | 以 v0.3.1 实际 ABI、授权模型和 EIP-712 结构核对；不要求 v0.3.2 的 4 槽位与 string slot 签名 |
| SCN-068 清算/ADL | 按 v0.3.1 实际定价链路记录结果；v0.3.2 的负点差 floor-at-0 与修复后手续费档位另在 v0.3.2 验收 |
| E2E-TRD-035～041 历史与事件 | 按 v0.3.1 ABI 解析；不得用 v0.3.2 删除字段后的事件结构反推历史结果 |

这些差异只解释 v0.3.1，不降低共享用例对资金安全、状态一致性和证据完整性的要求。
