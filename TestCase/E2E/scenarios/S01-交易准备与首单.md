# S01 交易准备与首单

**目标**：验证用户从陌生环境进入，到确认市场、钱包、网络、授权和首笔成交的完整信任链。

**主要依据**：交易指南、Flash 同意与风险披露、页面字段计算公式、Base Sepolia 环境基线。

## 套件退出条件

- 账户位于 Base Sepolia；
- 无残留首单仓位；
- 记录 Standard 与 Flash 首单签名次数；
- 保存连接、首单预览、持仓和历史证据。
