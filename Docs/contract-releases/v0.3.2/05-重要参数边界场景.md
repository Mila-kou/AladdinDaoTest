除非卡片另有说明，组 1/2 使用以下受控配置（tx-fork，CONFIG_KEEPER 经 `src/config/Config.sol::setUint/setInt` 写入；均为 fixture 值，非部署值）：

| `BID/ASK_ORDER_BOOK_DEPTH` | 10000000000000000000000000000000000000（1e37，1e30 精度） | 10,000,000 USD |
| `MAX_PRICE_IMPACT_SPREAD` | 5000000000000000（5e15） | 0.5% |
| `SKEW_IMPACT_FACTOR` | 0（隔离用）；负点差卡片单独写 10000000000000000（1e16） | 0 / 0.01 |

| oracle ETH 价 | min=max=3000000000000000（3e15，1e12 精度）即 3,000 USD；双价卡片另注 | — |
| 基准订单 | 开/减仓 usdDelta = 10000000000000000000000000000000000（1e34，1e30 精度）即 10,000 USD | — |

**公共推导（后续卡片直接引用，锚点 `src/pricing/PositionPricingUtils.sol::getDynamicSpread/getPriceImpactSpread`，字段规则 §6）**：

- 线性项 = orderSize×1e18/depth = 1e34×1e18/1e37 = **1e15**；指数 x = mulDiv(1e34, 6e17, 1e37) = **6e14**（0.0006）；exp(x)−1e18 ≈ 6.0018e14 < 1e15，故 `SignedMath.max` 取线性项；
- `priceImpactSpread` = 1e15/100 = **1e13**（整数除法精确）；
- skewImpact=0 时 `rawSpread` = 0 + 1e14 + 1e13 = **110000000000000（1.1e14，0.011%）**。
- 执行价（`src/position/PositionUtils.sol::getExecutionPriceForIncrease/getExecutionPriceForDecrease`）：多头开仓 = price.max×(1e18+spread)/1e18（floor）；多头减仓 = price.min×(1e18−spread)/1e18（floor）。
