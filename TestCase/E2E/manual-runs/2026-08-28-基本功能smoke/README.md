## 3. 钱包与连接（执行前置）

- 连接弹窗仅两个入口：**Browser Wallet**（浏览器注入钱包通用入口）与 **Coinbase Wallet**。**没有 Rabby / MetaMask 专属图标**；曾短暂出现 "More Available" 分组，弹窗 DOM 内实际只有上述两个按钮（无更多钱包时该分组为空，展开不了是现状而非误操作）。
- **Rabby 接入方式**：走 Browser Wallet 入口。若同时装有 MetaMask 等多个插件钱包，需在 Rabby 设置里开启 **"Set Rabby as default wallet"**（默认钱包），让 Rabby 接管注入入口；否则由其它插件抢占，表现为"点了没反应/弹错钱包"。冲突严重时临时停用其它钱包插件后刷新页面再连。
- 执行钱包（2026-08-28 实际）：`0xEEeA••••B119`（已连接成功；完整地址执行时从钱包/回执补记）。
