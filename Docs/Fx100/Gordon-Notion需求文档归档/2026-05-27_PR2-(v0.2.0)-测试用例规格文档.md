## 第2组：执行费补贴修复（7c1ad5b — FIXME-001）
### TC-EFX-01：Token 模式订单转换为 USD 后满足补贴条件
**测试函数**：`test_fixme_001_tokenSizeComparedToUsdMinOrderSize`（`vm.skip` 已移除）
**验证点**：
- `sizeDeltaTokens = 1e18`，`midPrice = 2000e12`，`minOrderSize = 100e30`
- `estimatedOrderSizeUsd = 1e18 * 2000e12 = 2000e30 >= 100e30` → 应获补贴
- 原 bug 路径：`1e18 < 100e30` → 不补贴（已修复）
**预期结果**：PASS（之前为 SKIP）
### TC-EFX-02（新增）：USD 模式订单直接比较，逻辑不变
**测试函数**：`test_executionFee_usdMode_directComparison`
**验证点**：`isSizeDeltaUsd=true`，`sizeDelta=5000e30`（USD），`minOrderSize=100e30`，无需乘以价格，`5000e30 >= 100e30` → 应获补贴
**预期结果**：PASS
### TC-EFX-03（新增）：Token 模式订单价格过低不达补贴阈值
**测试函数**：`test_executionFee_tokenMode_belowThreshold`
**验证点**：`sizeDelta=1e15`（0.001 ETH），`midPrice=50e12`（ETH=\$50），`minOrderSize=100e30`，`estimatedUsd = 1e15 * 50e12 = 50e27 < 100e30` → 不补贴
**预期结果**：PASS

### TC-PUC-05（新增）：isInsolventCloseAllowed — token 模式全平仓检测
**文件**：`test/unit/order/InsolventClose.t.sol`（新文件）
**测试函数**：
- `test_isInsolventClose_tokenMode_fullClose_allowed` — TC-PUC-05a
- `test_isInsolventClose_tokenMode_partialClose_notAllowed` — TC-PUC-05b
- `test_isInsolventClose_usdMode_fullClose_allowed` — TC-PUC-05c
- `test_isInsolventClose_usdMode_partialClose_notAllowed` — TC-PUC-05d
- `test_isInsolventClose_tokenMode_matchesUsd_notFullClose` — TC-PUC-05e（边界）
**验证点**：

token 模式：`sizeDelta < position.sizeInTokens()` → `isInsolventCloseAllowed = false`
USD 模式：`sizeDelta == position.sizeInUsd()` → `isInsolventCloseAllowed = true`
USD 模式：`sizeDelta < position.sizeInUsd()` → `isInsolventCloseAllowed = false`
**预期结果**：全部 PASS
