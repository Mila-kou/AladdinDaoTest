## 一、sizeInUsd 是纯 USD，不是 USDC
### 计算路径
```javascript
用户输入（前端）: Pay = 10 USDC + 100x 杠杆

① SDK 换算：
   collateralUsd = 10 USDC × USDC_oracle_price
                = 10 × 10^6 (raw) × (usdc_price / 10^6)
                ≈ $9.999 USD     ← 用当前 oracle 价格，不是固定 $1

② SDK 计算仓位大小：
   sizeDeltaUsd = collateralUsd × leverage = $9.999 × 100 = $999.9 × 10^30

③ 合约存储：
   position.sizeInUsd = $999.9 × 10^30   ← 纯 USD，不是 USDC
```
### 前端注意事项
- **Size 输入框**显示和接收的是 **USD 金额**（如 \$1000），SDK 负责换算
- USDC oracle 实时价格 ≈ \$0.9998\~\$0.9999（非精确 \$1）
- 10 USDC ≠ \$10 USD，差距约 0.01%\~0.02%
- **建议**：Pay 栏标注「USDC」，Size 栏标注「USD」，避免用户混淆

## 二、collateralAmount 存的是 USDC 原生数量
```solidity
// 仓位存储（raw USDC count，6位小数）
position.collateralAmount = 10_001_222   // = 10.001222 USDC

// 每次校验时实时换算 USD 价值
collateralUsd = position.collateralAmount() × collateralTokenPrice.min
             = 10.001222 USDC × $0.9999/USDC = $10.000 USD
```
这意味着：**USDC 大幅贬值会直接导致保证金 USD 价值下降，触发清算**。
合约**每次都用当前 USDC oracle 价格重新换算**：

## 三、USDC 价格：min vs max 的使用规则
合约始终按**对用户最不利**的方向选价，保护协议：

## 四、100x 高杠杆时的精度风险
### 问题根源
USC oracle 价格 ≈ \$0.9998（非精确 \$1），加上开仓手续费从保证金扣除：
```javascript
实际流程（100x，10 USDC）：
  collateralUsd = 10 × $0.9998 = $9.998
  开仓费（0.02%）= $9.998 × 100 × 0.02% = $0.020
  实际可用保证金 = $9.998 - $0.020 = $9.978

  sizeInUsd = $9.978 × 100 = $997.8   ← 非 $1000
```
### 可能失败的情况
- `sizeInUsd < MIN_POSITION_SIZE_USD`（最小仓位限制）
- `collateralUsd < MIN_COLLATERAL_USD`（最小保证金限制）
- 用户输入「10 USDC + 100x」，期望 \$1000 仓位，但实际只有 \$997
### 前端建议
1. **最大杠杆显示**：如合约允许 100x，前端建议显示 `99.9x` 或计算时留 0.05% buffer
2. **Pay 栏提示**：显示「实际仓位 ≈ \$xxx（受 USDC 汇率影响）」
3. **验证预检**：提交前用 SDK 计算实际 `sizeDeltaUsd` 和 `collateralDeltaUsd`，低于最小值则提示

## 五、与 GMX v2 的关系
FX100 在这一部分与 GMX v2 设计**完全相同**：
- GMX 主网 USDC 同样用 Chainlink USDC/USD feed，价格非精确 \$1
- GMX 主网同样存 raw token 数量，用实时 oracle 价格重算 USD
- GMX 主网同样全部用 `min` 对 trader 估值，用 `max` 对 LP 侧估值
- 这是协议设计的刻意选择，不是 FX100 特有行为

## 六、测试用例 Checklist
### USDC 计价相关
- [ ] 开仓时 `sizeInUsd` = `collateralUSD × leverage`（注意是 USD 不是 USDC 数量 × leverage）
- [ ] 关仓时 PnL 以 USD 结算，输出 USDC 数量 = PnL_USD / USDC_price
- [ ] 修改 MockUSDCOracle 价格为 \$0.95，验证 collateralUsd 同比下降 5%
- [ ] USDC 价格暴跌模拟：确认触发清算的条件正确
### 边界条件
- [ ] 10 USDC + 100x：验证 `sizeInUsd` ≈ \$997\~\$1000（受 oracle 偏差影响）
- [ ] 恰好在最小保证金边界时，USDC oracle 偏差 0.02% 是否会触发验证失败
- [ ] 费用扣除后保证金刚好低于清算线时的行为
### Oracle 价格
- [ ] USDC minPrice ≈ maxPrice（正常情况下偏差 \< 0.02%）
- [ ] 计算 collateralUsd 用 minPrice，结果 ≤ 用 maxPrice 的结果
- [ ] 高 spread 情况下（如 USDC 脱锚），min/max 差距变大，各操作路径是否正确
