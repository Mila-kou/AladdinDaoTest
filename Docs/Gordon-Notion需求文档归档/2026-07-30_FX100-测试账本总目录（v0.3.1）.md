## 20 条预期失败的重点

已登记缺陷覆盖：

- Subaccount expiresAt 语义
- MarketUtils false return
- Swap error event
- DataStore 下溢 / 溢出自定义错误
- Price Impact 数学边界
- Vault shortage withdrawal
- RemainingCostUsd 单位
- minOutputAmount 未执行
- Decrease rounding exhaustion
- 清算 fee tier 丢失
- Price Impact exp 指数无上界

## 16 条跳过的主要原因

1. Referral 模块整体延期。
2. 三方费用分账尚未完成部署 / 运维切换。
3. Relay 边界待合约修复。
4. Token 模式超额抵押退款待实现。
5. MAX_PNL_FACTOR 开仓侧是否接入待产品决策。
6. ExternalHandler refund token 去重待实现。

## 与旧 E2E 清单的关系

旧的 06-16 手工核对清单仍是精确账本业务场景的重要子集，但不再代表全仓库测试总量。

统计采用以下优先级：

1. 本页 v0.3.1 测试账本：全仓库当前真实执行结果。
2. 06-16 手工核对清单：精确账本 E2E 子集状态。
3. 早期设计规范：测试设计来源，不作为最新执行状态。

## 维护约定

- 新测试必须加入对应 catalog 子文档。
- 状态必须来自真实 `forge test --json`。
- 任何失败 / 跳过状态变化都需同步更新非通过清单。
