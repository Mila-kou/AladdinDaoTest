## 维护规则

1. 公式与参数定义绑定合约 commit；参数值另外绑定 deployment、chainId 和 blockNumber。**前端与 Keeper 公式绑定 `fx100-apps` 的 head**（`CURRENT.json` `frontend.head`）——`develop` 是移动分支，行号随 rebase 失效，引用时必须带 head、以函数名定位。
2. 后续版本必须新建平级目录，不得直接覆盖本快照。
3. 本次快照不包含 `Github/fx100-contracts@release-v0.3.2` 工作树中未提交的本地补丁。
