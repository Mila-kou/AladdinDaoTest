## 概述
### 目的
现有 `test/integration/LimitOrders.t.sol` 验证限价/止损订单的**触发逻辑**（执行成功/失败的方向性断言），但不验证执行后的**精确 USDC 账本**。
本套件补充验证：订单以**触发时的 oracle 价格**执行，对应精确的 OI 变化、LP 盈亏、trader 余额。
### 与市场订单账本的核心差异

**acceptablePrice 规则（零 spread 场景）：**
- 开仓类：`isLong ? type(uint256).max : 0`
- 平仓类：`isLong ? 0 : type(uint256).max`

## 第二节：参数基准与精确计算
```javascript
ENTRY_PRICE      = 2_000e30   → oracle 归一化 = 2_000e12
ORDER_SIZE       = 20_000e30  (20k USD)
ORDER_COLLATERAL = 10_000e6   (10k USDC)
LP_SEED          = 1_000_000e6

sizeInTokens_entry = ORDER_SIZE / 2_000e12 = 10e18
```
### 各场景精确值
**LO-1（LimitIncrease 抄底，triggerPrice = 1_600e12）：**
```javascript
sizeInTokens = ORDER_SIZE / triggerPrice = 20_000e30 / 1_600e12 = 12.5e18
OI delta:
  oiLongUsd    += ORDER_SIZE = 20_000e30
  oiLongTokens += 12.5e18
trader delta = -ORDER_COLLATERAL
LP delta     = 0
```
**LO-2（StopIncrease 追涨，triggerPrice = 2_400e12）：**
```javascript
sizeInTokens = 20_000e30 / 2_400e12 ≈ 8.333e18
OI delta:
  oiLongUsd    += 20_000e30
  oiLongTokens += 8.333e18
trader delta = -ORDER_COLLATERAL
LP delta     = 0
```
**LO-3（LimitDecrease 止盈，entryPrice=2000，triggerPrice = 2_500e12）：**
```javascript
pnl = 10e18 × (2_500e12 - 2_000e12) / 1e24 = 5_000e6 = 5000 USDC

trader delta = +ORDER_COLLATERAL + 5_000e6 = +15_000e6
LP delta     = -5_000e6
OI 清零
```
**LO-4（StopLossDecrease 止损，entryPrice=2000，triggerPrice = 1_500e12）：**
```javascript
pnl = 10e18 × (1_500e12 - 2_000e12) / 1e24 = -5_000e6

trader delta = +ORDER_COLLATERAL - 5_000e6 = +5_000e6
LP delta     = +5_000e6
OI 清零
```
**LO-5（LimitDecrease 空头止盈，entryPrice=2000，triggerPrice = 1_500e12）：**
```javascript
short pnl = 10e18 × (2_000e12 - 1_500e12) / 1e24 = 5_000e6

trader delta = +ORDER_COLLATERAL + 5_000e6 = +15_000e6
LP delta     = -5_000e6
OI 清零
```

## 第三节：5 个测试场景
### LO-1：LimitIncrease 多头（抄底）
```javascript
步骤：
  s0 = _snapshot(...)  // 无持仓
  创建 LimitIncrease 订单（不执行）
  s1 = _snapshot(...)  // 挂单期间状态未变

  _assertZeroSum(s0, s1)
  assertEq(s1.market.oiLongUsd, 0, "挂单期间 OI 不变")

  // 价格下跌到触发价，执行订单
  _setMockPrice(WNT, 1_600e30, 1_600e30)
  orderHandler.executeOrder(orderKey, _oracleParams(WNT))
  s2 = _snapshot(...)

  _assertZeroSum(s1, s2)
  _assertExactAccount(s1, s2, -int256(ORDER_COLLATERAL), 0)
  assertEq(s2.market.oiLongUsd,    ORDER_SIZE)
  assertEq(s2.market.oiLongTokens, ORDER_SIZE / 1_600e12)  // 使用触发价格
```
---
### LO-2：StopIncrease 多头（追涨）
```javascript
步骤：
  创建 StopIncrease 订单

  // 触发前尝试执行 → 应 revert
  vm.expectRevert()
  orderHandler.executeOrder(orderKey, _oracleParams(WNT))

  // 价格上涨到触发价，执行订单
  _setMockPrice(WNT, 2_400e30, 2_400e30)
  orderHandler.executeOrder(orderKey, _oracleParams(WNT))

  uint256 expTokens = ORDER_SIZE / 2_400e12
  assertApproxEqAbs(s_after.market.oiLongTokens, expTokens, 1)
  _assertExactAccount(s0, s1, -int256(ORDER_COLLATERAL), 0)
```
---
### LO-3：LimitDecrease 多头（止盈）
```javascript
步骤：
  _openLong(ORDER_COLLATERAL, ORDER_SIZE)  // 以 2000 开多仓
  创建 LimitDecrease 订单（trigger = 2_500e12）

  // 价格上涨，触发止盈执行
  _setMockPrice(WNT, 2_500e30, 2_500e30)
  orderHandler.executeOrder(orderKey, _oracleParams(WNT))

  _assertZeroSum(s0, s1)
  _assertExactAccount(s0, s1, +int256(ORDER_COLLATERAL) + 5_000e6, -5_000e6)
  _assertOI(s0, s1, -int256(ORDER_SIZE), 0, -int256(sizeInTokens_entry), 0)
  // LP 支付了5000 USDC
```
---
### LO-4：StopLossDecrease 多头（止损）
```javascript
步骤：
  _openLong(ORDER_COLLATERAL, ORDER_SIZE)
  创建 StopLossDecrease 订单（trigger = 1_500e12）

  // 价格下跌，触发止损执行
  _setMockPrice(WNT, 1_500e30, 1_500e30)
  orderHandler.executeOrder(orderKey, _oracleParams(WNT))

  _assertZeroSum(s0, s1)
  _assertExactAccount(s0, s1, +int256(ORDER_COLLATERAL) - 5_000e6, +5_000e6)
  _assertOI(s0, s1, -int256(ORDER_SIZE), 0, -int256(sizeInTokens_entry), 0)
  // LP 从止损中获益 5000 USDC
```
---
### LO-5：LimitDecrease 空头（止盈）— 对称性验证
```javascript
步骤：
  _openShort(ORDER_COLLATERAL, ORDER_SIZE)  // 以 2000 开空仓
  创建 LimitDecrease 空头止盈订单（trigger = 1_500e12）

  // 价格下跌，空头止盈触发
  _setMockPrice(WNT, 1_500e30, 1_500e30)
  orderHandler.executeOrder(orderKey, _oracleParams(WNT))

  _assertZeroSum(s0, s1)
  _assertExactAccount(s0, s1, +int256(ORDER_COLLATERAL) + 5_000e6, -5_000e6)
  // 与 LO-3（多头止盈）结果完全对称：LP 均支付 5000 USDC
```
