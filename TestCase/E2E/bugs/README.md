# 缺陷单目录（按发现版本分目录）

- 缺陷单按**发现时的主测基线版本**归档到 `bugs/<version>/`；当前主测基线以 [`Docs/contract-releases/CURRENT.json`](../../../Docs/contract-releases/CURRENT.json) 为准。
- [`v0.3.1/`](v0.3.1/) — 25 张缺陷单（2026-08-28 基本功能 smoke + 2026-08-30 移动端 smoke + 2026-09-04 提取保证金专项，前端基线 fx100-apps@develop，合约基线 release-v0.3.1）。
- [`v0.3.2/`](v0.3.2/) — v0.3.2 版本测试发现的新缺陷一律落这里；旧版本缺陷在新版本复测的结果回写原单（复测记录注明版本与日期），不迁移、不开新单，除非新版本行为构成新缺陷。
- 命名沿用工作区规范：`BUG-<域>-<助记>-NNN-<中文摘要>.md`，六字段齐全、证据可追溯（05 标准：无证据的勾选不算通过）。
