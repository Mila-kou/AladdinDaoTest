# 概述
验证风控超限后订单被**静默取消**（非 revert），且状态完全不变。
---
# 关键架构发现：OrderHandler 静默取消
`OrderHandler.executeOrder()` 内部使用 try/catch：
- 任何内部 revert → 静默取消订单 + 退还抜资金
- **调用方收不到 revert**
- `vm.expectRevert()` 对 executeOrder 路径无效
**两种 helper 的区别：**
<table header-row="true">
<tr>
<td>Helper</td>
<td>用途</td>
</tr>
<tr>
<td>`_openLong()`</td>
<td>预期开仓成功，内含 assertGt(sizeInUsd\>0)</td>
</tr>
<tr>
<td>`_attemptOpenLong()`</td>
<td>预期被风控取消，无 assertGt，专用于 P7</td>
</tr>
</table>
