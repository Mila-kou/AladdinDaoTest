# 项目准备清单

## A. Tenderly 环境

- [ ] TX_FORK 普通 RPC
- [ ] TX_FORK Admin RPC
- [ ] ORACLE_FORK 普通 RPC
- [ ] ORACLE_FORK Admin RPC
- [ ] TIME_FORK 普通 RPC
- [ ] TIME_FORK Admin RPC
- [ ] 三个 Fork 的 chainId
- [ ] 三个 Fork 的固定起始区块
- [ ] Oracle/Time Fork 运行期 State Sync 关闭
- [ ] 每个 Fork 的 baseline ID 或可重复重建方法
- [ ] TX/Oracle/Time Fork 初始化时均运行 `env:init:mock`，生成 `default-mock`
- [ ] `config/mock-resources.json` 已记录各 Fork 的 bundleId、Market、Index Token/Oracle、USDC/Oracle 和 marketIndex
- [ ] Tenderly API access token

## B. 已部署协议

- [ ] 核心合约地址
- [ ] Proxy implementation 地址与版本
- [ ] release/commit
- [ ] 固定 ABI
- [ ] ETH/BTC market index
- [ ] Index/Collateral/WNT/Vault 地址
- [ ] Token decimals
- [ ] Controller 与各 Keeper 地址
- [ ] 测试账户私钥和资金准备方式

## C. 页面数据链路

- [ ] 钱包交易 RPC 指向目标 Fork
- [ ] 页面 Reader 指向同一 Fork
- [ ] Keeper 指向同一 Fork
- [ ] Indexer/历史数据指向同一 Fork，或存在 E2E Adapter
- [ ] 页面市场列表可以发现 Synthetic Market
- [ ] 页面缓存可在 baseline 恢复后刷新

## D. Synthetic Market

- [ ] 用例只引用登记过的 Bundle Alias（默认 `default-mock`），不得硬编码 Mock 地址
- [ ] Mock Index Token
- [ ] 环境共享 Collateral Token（当前 USDC）
- [ ] Index Mock Oracle 与 USDC Mock Oracle 均已配置 provider、min/max、multiplier、heartbeat
- [ ] 市场注册和参数初始化脚本
- [ ] 初始流动性
- [ ] Funding/OI/风险/费用参数
- [ ] 页面 symbol/decimals/market metadata
- [ ] Reader/Indexer 市场查询

## E. 准入命令

```bash
npm install
npm run typecheck
npm run config:validate -- <manifest>
npm run doctor
npm run env:show:mock
```

只有 doctor 为 READY，才开始编写场景测试。
