# 概述
现有 `MultiMarket.t.sol` 只做方向性断言。本套件验证 ETH / WBTC 双市场下的**精确 USDC 账本**。
---
# 核心机制
- **ETH 市场**（index 1）和 **WBTC 市场**（index 2）共享同一个 `lpVault`
- 每个市场有独立的 OI key：`cumulativeOpenCostsKey(mi, isLong)`
- LP 的 `totalAssets` 受两个市场的 P&L 共同影响
## ❗ WBTC Oracle 归一化（重要发现）
Mock oracle 对所有非 USDC token（包括 WBTC 8 decimals）均使用相同乘数 **1e12**：
```javascript
WBTC normalizedPrice = 60_000e30 × 1e12 / 1e30 = 60_000e12  (与 ETH 同量级)
sizeInTokens_WBTC = 20_000e30 / 60_000e12 ≈ 333e15
```
