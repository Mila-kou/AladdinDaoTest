## 测试逻辑说明
### T26：clearAutoCancelOrders 触发
```plain text
路径：MarketDecrease 全平仓 → sizeInUsd=0
      → ExecuteOrderUtils.executeOrder 检测 sizeInUsd==0
      → clearAutoCancelOrders 遍历并取消 autoCancel 订单
验证：执行 slKey（已被取消）→ revert EmptyOrder
```
### T27a（USD 模式）& T27b（token 模式）：执行费补贴
```plain text
USD 模式：estimatedOrderSizeUsd = order.sizeDelta()
Token 模式：estimatedOrderSizeUsd = sizeDelta * indexTokenPrice.midPrice()
            = 10e18 WNT * 2000e12 = 20000e30 = ORDER_SIZE
设置 executionFeeSubsidizeKey = ORDER_SIZE → 条件满足 → executionFee = 0
验证：仓位成功开仓（补贴路径无 revert）
```
### T28：重复执行防护
```plain text
ExecuteOrderUtils.executeOrder 第一步：OrderStoreUtils.remove(key)
第二步：validateNonEmptyOrder(order) — 使用调用时已加载的 order
→ 第一次执行后 key 已从 store 移除
→ 第二次 executeOrder(key) 加载空 order → validateNonEmptyOrder → revert EmptyOrder
```
### T31 & T32：graceEnd 计算
```plain text
graceEnd = block.timestamp + gracePeriodBase * multiplier / WEI_PRECISION

Tier=0：multiplier = 8e18，gracePeriodBase = 15s
        graceEnd = timestamp + 15 * 8e18 / 1e18 = timestamp + 120s ✅

Tier=1：multiplier = 16e18（测试中设置），gracePeriodBase = 15s
        graceEnd = timestamp + 15 * 16e18 / 1e18 = timestamp + 240s ✅

注：referralStorage.setReferrerTier(trader, 1) 需要 onlyGov，
    测试合约 = admin = gov，直接调用即可。
```
