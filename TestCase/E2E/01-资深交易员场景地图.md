# 资深交易员场景地图

## 1. 交易员会怎样使用 FX100

资深交易员的操作不是固定按钮序列，而是“观察 → 决策 → 执行 → 风控 → 退出 → 复盘”的循环。

| 阶段 | 交易员判断 | 典型操作 | 对应场景 |
|---|---|---|---|
| 进入 | 网络、钱包、市场是否可信 | 连接钱包、切链、选 BTC/ETH、核对行情 | SCN-001～008 |
| 观察 | 趋势、拥挤、资金费、流动性 | 比较 K 线/Oracle、OI 多空、Funding、Available Liquidity | SCN-009、045～052、073～080 |
| 建仓 | 立即成交还是等价位 | 市价开多/开空、低吸/高抛限价、突破追单 | SCN-009～014、065、069～070 |
| 保护 | 盈亏目标和最大损失 | 多空 TP/SL、括号单、仅减仓、保护期、Funding 清算风险 | SCN-015～016、033～041、066～069、072、079 |
| 调整 | 观点加强、风险变化 | 加仓、调杠杆、加减保证金、改触发价 | SCN-017、025～028、071、077 |
| 退出 | 分批兑现或紧急离场 | 25%/50% 分批、多空条件平仓、市价全平 | SCN-023～024、029～030、066～070、072、077 |
| 高频 | 减少签名摩擦 | Flash、一键改撤、Cancel All | SCN-053～057 |
| 异常 | 不重复下单、不丢资金 | 等待、重试、撤销、核对退款/冻结 | SCN-018～020、059～062、070～071 |
| 复盘 | 成交是否符合预期 | 核对 Entry、PnL、Est. Receive、Funding、费用和历史 | SCN-021～032、045～049、073～080 |

## 2. 典型资深交易策略

### 2.1 趋势突破

1. 观察价格、OI 和资金费，确认趋势未过度拥挤。
2. 在现价上方挂多头突破单，或现价下方挂空头突破单。
3. 同时设置止损和分批止盈。
4. 触发后核对实际成交价包含当时点差，而不是把触发价当限价上限。
5. 趋势延续时加仓；风险放大时加保证金或上移止损。

覆盖：SCN-009、012～016、025～030、045～050、065～072。

### 2.2 反转低吸/高抛

1. 选择流动性充足的市场。
2. 在现价下方挂限价开多，或现价上方挂限价开空。
3. 价格未触及时修改价位或撤单。
4. 成交后确认 Entry Price 由执行价决定，并复核 Price Impact。

覆盖：SCN-010～011、017～018、021～022、048～050、069～071。

### 2.3 高频短线

1. 采用 Flash 降低逐笔签名摩擦。
2. 连续开平仓、改单和撤单。
3. 使用 Cancel All 在行情变化时原子撤销全部挂单。
4. 对任何 Pending 超时先确认 keeper 状态，避免重复下单。

覆盖：SCN-053～062。

### 2.4 高杠杆风险管理

1. 不直接相信理论 100x，先看实际最大杠杆和费用/点差 buffer。
2. 价格接近危险区时优先补保证金或全平，不做不足比例的部分平仓。
3. 利用保护期处理瞬时插针，但不把保护期误认为永不清算。
4. 记住加仓不会重置保护倒计时，Funding 和 USDC 价格也会侵蚀安全垫。

覆盖：SCN-033～044、045～047、079。

### 2.5 跨市场组合

1. 同时持有 ETH 与 BTC，分别核对市场参数和精度。
2. 控制共享 LP 流动性、不同市场 OI 上限与大单冲击。
3. 切市场或切账户后确认持仓、订单和历史不串数据。

覆盖：SCN-031～032、050～052、064、080。

### 2.6 Funding 成本管理

1. 先看 Long/Short OI 和页面两侧费率，但不把瞬时 OI Skew 直接当成 EMA Skew。
2. 按页面符号约定确认本仓是支付还是获得，特别注意均衡市场的 Long Floor。
3. 长持时把 Funding 作为有效保证金的一部分，不只看价格 PnL。
4. 加仓、补/取保证金、部分平、TP/SL 和全平后，核对 Funding 只结算一次且基准已刷新。
5. 价格不变也要监控 Funding-only 清算风险。

覆盖：SCN-029～030、045～047、073～080。

## 3. 交易员验收标准

交易员视角的通过，不只是“交易成功”：

- 成交类型、方向、规模和触发逻辑与意图一致；
- 实际成交价、点差和费用在签名前可理解；
- 持仓的 Entry、杠杆、PnL、Funding、清算价与权威数据一致；
- Cancel、Freeze、Revert 和 Pending 能明确区分下一步动作；
- 任何失败都不会导致重复仓位、资金去向不明或挂单无声消失；
- 全平或撤单后，持仓、关联 TP/SL、余额和历史形成闭环。
