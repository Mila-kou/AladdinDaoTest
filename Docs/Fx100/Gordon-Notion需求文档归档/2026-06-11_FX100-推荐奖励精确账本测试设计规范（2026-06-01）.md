# USDC 流程
```javascript
Affiliate 注册 code → Trader 绑定 code → Trader 开仓
  → affiliateRewardKey += rewardAmt    [DataStore，USDC 仍在 posVault]
  → claimAffiliateRewards()
    → posVault → affiliate receiver     [实际 USDC 转移]
    → affiliateRewardKey 清零
```
# 精确计算公式
```javascript
positionFeeAmt = SIZE x FEE_FACTOR / FLOAT_PRECISION / USDC_PRICE
              = 10_000e30 x 1e28 / 1e30 / 1e24 = 100e6 = 100 USDC

rewardAmt = positionFeeAmt x affiliateFactor / FLOAT_PRECISION
  discountShare=0:   affiliateFactor = basisPointsToFloat(1000) = 1e29
                     rewardAmt = 100e6 x 1e29 / 1e30 = 10e6 = 10 USDC
  discountShare=50%: affiliateFactor = 1e29 - basisPointsToFloat(500) = 5e28
                     rewardAmt = 100e6 x 5e28 / 1e30 = 5e6 = 5 USDC
```
